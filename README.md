## Project Overview

This project contains my Advanced Networking assignment completed as part of my Security and Network Engineering studies at Eduvos.

The project focuses on the redesign of the Nexus Logistics network from a flat Layer 2 infrastructure into a secure, segmented and scalable network architecture. The network was designed and simulated using Cisco Packet Tracer.

## Technologies Used

* Cisco Packet Tracer
* Cisco IOS
* IPv4
* VLSM
* VLANs
* Inter-VLAN Routing
* OSPF
* Access Control Lists (ACLs)
* Rapid-PVST+
* Port Security

## Network Architecture

The proposed network uses a hierarchical network design with separate distribution and access functions. VLAN segmentation is used to separate departments and control broadcast traffic.

ACLs are implemented to restrict communication between network segments and improve network security.
